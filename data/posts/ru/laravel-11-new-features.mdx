## Новая эра PHP разработки: Добро пожаловать в Laravel 11

Laravel продолжает оставаться самым популярным PHP-фреймворком в мире, и релиз Laravel 11 подтверждает этот статус. Эта версия приносит значительное упрощение структуры проекта, новые мощные инструменты и крупные улучшения производительности. Создатели фреймворка сосредоточились на том, чтобы сделать процесс разработки максимально быстрым и комфортным (Developer Experience — DX).

В этой статье мы подробно рассмотрим наиболее важные изменения в Laravel 11 и объясним, как они повлияют на написание кода в ваших новых проектах.

## 1. Максимально упрощенная структура каталогов

Самое заметное изменение для разработчиков, создающих новый проект на Laravel 11, — это кардинально уменьшенное количество файлов по умолчанию. Многие файлы конфигурации, провайдеры (Providers) и посредники (Middleware) были удалены или перенесены непосредственно в ядро фреймворка.

* **Один провайдер вместо многих:** Вместо нескольких сервис-провайдеров в папке `app/Providers` теперь по умолчанию остается только один — `AppServiceProvider`. Настройки маршрутизации и обработки событий теперь происходят в центральном файле конфигурации приложения.
* **Нет папки config по умолчанию:** Да, вы все правильно поняли! В новом проекте папка конфигураций пуста. Все опции настраиваются через файл `.env`. Если вам все же нужно изменить дефолтные параметры, вы можете опубликовать нужный конфиг с помощью команды:

```bash
php artisan config:publish --all
```

* **Упрощенный файл маршрутов:** API и WebSockets маршруты теперь не создаются по умолчанию. Для их добавления используются новые лаконичные команды:

```bash
php artisan install:api
php artisan install:broadcasting
```

## 2. Новая точка входа в файле bootstrap/app.php

Все настройки поведения приложения, посредников (middleware) и исключений (exceptions) теперь сконцентрированы в одном файле `bootstrap/app.php`. Это значительно упрощает глобальную конфигурацию:

```php
use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    ->withMiddleware(function (Middleware $middleware) {
        // Добавление глобальных посредников
    })
    ->withExceptions(function (Exceptions $exceptions) {
        // Кастомный рендеринг исключений
    })->create();
```

## 3. SQLite по умолчанию

Для новых приложений Laravel 11 теперь использует SQLite в качестве базы данных по умолчанию. Это позволяет разработчикам начать работу над проектом мгновенно после запуска `laravel new`, без необходимости устанавливать локальные серверы MySQL или PostgreSQL или настраивать Docker-контейнеры на начальных этапах. База данных создается автоматически в виде обычного файла внутри проекта.

## 4. Новый инструмент Laravel Reverb

Одной из самых интересных новинок стала интеграция **Laravel Reverb** — первоклассного, невероятно быстрого WebSocket сервера, разработанного специально для приложений Laravel. Он полностью написан на PHP и совместим с протоколом Pusher. Reverb позволяет легко масштабировать real-time функционал вашего приложения без сторонних платных сервисов.

## Заключение

Laravel 11 делает шаг навстречу максимальной лаконичности кода и простоте масштабирования. Новая структура может показаться непривычной на первый взгляд, но она значительно ускоряет создание и поддержку проектов. Обновление до Laravel 11 — это отличный способ повысить продуктивность ваших разработчиков и приложения в целом.
