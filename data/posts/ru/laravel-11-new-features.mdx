        <h2>Новая эра PHP разработки: Добро пожаловать в Laravel 11</h2>
        <p>Laravel продолжает оставаться самым популярным PHP-фреймворком в мире, и релиз Laravel 11 подтверждает этот статус. Эта версия приносит значительное упрощение структуры проекта, новые мощные инструменты и крупные улучшения производительности. Создатели фреймворка сосредоточились на том, чтобы сделать процесс разработки максимально быстрым и комфортным (Developer Experience — DX).</p>
        <p>В этой статье мы подробно рассмотрим наиболее важные изменения в Laravel 11 и объясним, как они повлияют на написание кода в ваших новых проектах.</p>
        
        <h2>1. Максимально упрощенная структура каталогов</h2>
        <p>Самое заметное изменение для разработчиков, создающих новый проект на Laravel 11, — это кардинально уменьшенное количество файлов по умолчанию. Многие файлы конфигурации, провайдеры (Providers) и посредники (Middleware) были удалены или перенесены непосредственно в ядро фреймворка.</p>
        <ul>
          <li><strong>Один провайдер вместо многих:</strong> Вместо нескольких сервис-провайдеров в папке <code>app/Providers</code> теперь по умолчанию остается только один — <code>AppServiceProvider</code>. Настройки маршрутизации и обработки событий теперь происходят в центральном файле конфигурации приложения.</li>
          <li><strong>Нет папки <code>config</code> по умолчанию:</strong> Да, вы все правильно поняли! В новом проекте папка конфигураций пуста. Все опции настраиваются через файл <code>.env</code>. Если вам все же нужно изменить дефолтные параметры, вы можете опубликовать нужный конфиг с помощью команды:
            <pre><code class="language-bash">php artisan config:publish --all</code></pre>
          </li>
          <li><strong>Упрощенный файл маршрутов:</strong> API и WebSockets маршруты теперь не создаются по умолчанию. Для их добавления используются новые лаконичные команды:
            <pre><code class="language-bash">php artisan install:api
php artisan install:broadcasting</code></pre>
          </li>
        </ul>

        <h2>2. Новая точка входа в файле <code>bootstrap/app.php</code></h2>
        <p>Все настройки поведения приложения, посредников (middleware) и исключений (exceptions) теперь сконцентрированы в одном файле <code>bootstrap/app.php</code>. Это значительно упрощает глобальную конфигурацию:</p>
        <pre><code class="language-php">&lt;?php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;

return Application::configure(basePath: dirname(__DIR__))
    -&gt;withRouting(
        web: __DIR__.'/../routes/web.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    -&gt;withMiddleware(function (Middleware $middleware) {
        // Добавление глобальных посредников
        $middleware-&gt;web(append: [
            \App\Http\Middleware\LocalizationMiddleware::class,
        ]);
    })
    -&gt;withExceptions(function (Exceptions $exceptions) {
        // Кастомный рендеринг исключений
    })-&gt;create();</code></pre>

        <h2>3. SQLite по умолчанию</h2>
        <p>Для новых приложений Laravel 11 теперь использует SQLite в качестве базы данных по умолчанию. Это позволяет разработчикам начать работу над проектом мгновенно после запуска <code>laravel new</code>, без необходимости устанавливать локальные серверы MySQL или PostgreSQL или настраивать Docker-контейнеры на начальных этапах. База данных создается автоматически в виде обычного файла внутри проекта.</p>

        <h2>4. Новый инструмент Laravel Reverb</h2>
        <p>Одной из самых интересных новинок стала интеграция <strong>Laravel Reverb</strong> — первоклассного, невероятно быстрого WebSocket сервера, разработанного специально для приложений Laravel. Он полностью написан на PHP и совместим с протоколом Pusher. Reverb позволяет легко масштабировать real-time функционал вашего приложения без сторонних платных сервисов.</p>

        <h2>Заключение</h2>
        <p>Laravel 11 делает шаг навстречу максимальной лаконичности кода и простоте масштабирования. Новая структура может показаться непривычной на первый взгляд, но она значительно ускоряет создание и поддержку проектов. Обновление до Laravel 11 — это отличный способ повысить продуктивность ваших разработчиков и приложения в целом.</p>
