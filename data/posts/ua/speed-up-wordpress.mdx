        <h2>Вступ: Чому WordPress зазвичай уповільнюється з часом?</h2>
        <p>WordPress — неймовірно зручна система управління контентом, яка дозволяє дуже швидко запустити сайт за допомогою готових тем та десятків плагінів. Проте, при встановленні великої кількості розширень, база даних обростає тимчасовими запитами (transients), файли CSS та JS дублюються, а сайт починає завантажуватися довше 5-7 секунд.</p>
        <p>Уповільнення роботи призводить до втрати клієнтів та зниження позицій у Google. У цій статті ми розглянемо 4 практичні кроки, які дозволять вам пришвидшити роботу вашого сайту на WordPress щонайменше вдвічі без значних витрат на дорогі сервери.</p>
        
        <h2>1. Очищення та оптимізація бази даних MySQL</h2>
        <p>Кожного разу, коли ви зберігаєте статтю або сторінку, WordPress створює резервну копію попереднього варіанту — ревізію (revision). За кілька років роботи в базі даних можуть накопичуватися тисячі непотрібних ревізій, що суттєво уповільнює пошук інформації.</p>
        <p>Додайте наступний рядок у ваш файл <code>wp-config.php</code>, щоб обмежити кількість ревізій статей до 3 (замість нескінченності):</p>
        
```php
define( 'WP_POST_REVISIONS', 3 );
```

        <p>Також встановіть плагін типу WP-Optimize чи Advanced Database Cleaner, щоб видалити застарілі транзитивні опції, коментарі у спамі та оптимізувати таблиці бази даних MySQL.</p>

        <h2>2. Впровадження якісного кешування сторінок</h2>
        <p>За замовчуванням при кожному візиті користувача WordPress динамічно генерує сторінку: робить запити до бази даних, інтерпретує PHP-код і віддає HTML. Це створює сильне навантаження на процесор.</p>
        <p>Плагіни кешування зберігають вже згенеровану HTML-сторінку та віддають її наступним користувачам миттєво.</p>
        <ul>
          <li><strong>LiteSpeed Cache:</strong> Найкращий безкоштовний плагін, якщо ваш хостинг працює на веб-сервері LiteSpeed. Він інтегрується на рівні сервера та забезпечує феноменальну швидкість.</li>
          <li><strong>WP Rocket:</strong> Преміум-плагін із дуже простим інтерфейсом, який автоматично налаштовує відкладене виконання JavaScript та оптимізує шрифти.</li>
          <li><strong>WP Super Cache:</strong> Надійне безкоштовне рішення від розробників самого WordPress (Automattic).</li>
        </ul>

        <h2>3. Оптимізація та ліниве завантаження медіа-файлів</h2>
        <p>Великі зображення є головним «важковаговиком» на сторінці. Використовуйте плагіни на кшталт Smush, Imagify або Converter for Media для автоматичного стиснення зображень при їх завантаженні та генерації версій у сучасному форматі **WebP**.</p>

        <h2>4. Видалення невикористовуваних скриптів та стилів (Asset Cleanup)</h2>
        <p>Багато плагінів (наприклад, Contact Form 5) завантажують свої файли CSS та JS на кожній сторінці сайту, навіть там, де немає жодної форми. Використовуйте плагін **Asset CleanUp** або **Perfmatters** для вибіркового вимкнення завантаження непотрібних скриптів на конкретних сторінках.</p>
