        <h2>Вступ: Чому автоматичне тестування критично важливе</h2>
        <p>Уявіть, що ви запустили нове оновлення коду, і через дрібну помилку в JavaScript форма оформлення замовлення на вашому сайті перестала працювати. Клієнти не можуть зробити покупки, ви втрачаєте гроші, а служба підтримки розривається від скарг. Ручне тестування кожного разу перед релізом займає години та не гарантує 100% покриття.</p>
        <p><strong>Cypress</strong> — це сучасний JavaScript-фреймворк для написання E2E (End-to-End) тестів безпосередньо в браузері. Він імітує реальні дії користувача (кліки, введення тексту, навігація) і допомагає переконатися, що весь критичний бізнес-функціонал сайту працює ідеально після будь-яких змін коду.</p>
        
        <h2>1. Написання першого E2E тесту на Cypress</h2>
        <p>Давайте створимо практичний тест для перевірки форми авторизації користувача. Тест буде перевіряти перехід на сторінку логіну, введення даних, відправку форми та успішний редирект до особистого кабінету.</p>
        
```javascript
// cypress/e2e/login.cy.js
describe('Форма авторизації користувача', () =&gt; {
  beforeEach(() =&gt; {
    // Відкриваємо головну сторінку сайту перед кожним тестом
    cy.visit('https://programist.pp.ua/ua');
  });

  it('Успішний вхід користувача з коректними даними', () =&gt; {
    // Переходимо на сторінку контактів або логіну
    cy.contains('Контакти').click();
    
    // Перевіряємо, що URL змінився на правильний
    cy.url().should('include', '/contact');

    // Знаходимо поля форми та вводимо тестові дані
    cy.get('input[name="name"]')
      .type('Тестовий Користувач')
      .should('have.value', 'Тестовий Користувач');

    cy.get('input[type="email"]')
      .type('test@example.com');

    cy.get('textarea[name="message"]')
      .type('Привіт! Це автоматичний тест форми через Cypress.');

    // Клікаємо кнопку відправки форми
    cy.get('button[type="submit"]').click();

    // Очікуємо успішного повідомлення на екрані
    cy.contains('Дякуємо! Ваше повідомлення успішно відправлено.').should('be.visible');
  });
});
```


        <h2>2. Перехоплення та тестування API запитів (Network Mocking)</h2>
        <p>Cypress надає унікальну можливість перехоплювати мережеві запити браузера за допомогою функції <code>cy.intercept()</code>. Це дозволяє протестувати поведінку інтерфейсу при повільному з'єднанні, помилці 500 чи з імітованими даними без навантаження на реальну базу даних:</p>
        
```javascript
it('Відображення помилки, якщо сервер повернув 500', () =&gt; {
  // Перехоплюємо POST запит на відправку форми та повертаємо помилку
  cy.intercept('POST', '/api/contact', {
    statusCode: 500,
    body: { error: 'Внутрішня помилка сервера' }
  }).as('submitForm');

  cy.get('button[type="submit"]').click();

  // Перевіряємо реакцію інтерфейсу
  cy.contains('Сталася помилка при відправці. Спробуйте пізніше.').should('be.visible');
});
```


        <h2>Висновок</h2>
        <p>Впровадження автоматизованих E2E тестів за допомогою Cypress суттєво підвищує надійність вашого продукту. Хоча написання тестів вимагає додаткового часу на початкових етапах, це повністю окупається під час підтримки та масштабування проекту, позбавляючи розробників від страху випадково зламати існуючий функціонал перед релізом.</p>
