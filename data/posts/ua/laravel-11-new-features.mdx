        <h2>Нова ера PHP розробки: Ласкаво просимо до Laravel 11</h2>
        <p>Laravel продовжує залишатися найпопулярнішим PHP-фреймворком у світі, і реліз Laravel 11 підтверджує цей статус. Ця версія приносить значне спрощення структури проекту, нові потужні інструменти та значні покращення продуктивності. Творці фреймворку зосередилися на тому, щоб зробити процес розробки максимально швидким і комфортним (Developer Experience — DX).</p>
        <p>У цій статті ми детально розглянемо найважливіші зміни в Laravel 11 та пояснимо, як вони вплинуть на написання коду у ваших нових проектах.</p>
        
        <h2>1. Максимально спрощена структура каталогів</h2>
        <p>Найпомітніша зміна для розробників, які створюють новий проект на Laravel 11, — це кардинально зменшена кількість файлів за замовчуванням. Багато файлів конфігурації, провайдерів (Providers) та посередників (Middleware) було видалено або перенесено безпосередньо в ядро фреймворку.</p>
        <ul>
          <li><strong>Один провайдер замість багатьох:</strong> Замість кількох сервіс-провайдерів у папці <code>app/Providers</code> тепер за замовчуванням залишається лише один — <code>AppServiceProvider</code>. Налаштування маршрутизації та обробки подій тепер відбуваються в центральному файлі конфігурації додатку.</li>
          <li><strong>Немає папки <code>config</code> за замовчуванням:</strong> Так, ви все правильно зрозуміли! У новому проекті папка конфігурацій порожня. Всі опції налаштовуються через файл <code>.env</code>. Якщо вам все ж потрібно змінити дефолтні параметри, ви можете опублікувати потрібний конфіг за допомогою команди:
            <pre><code class="language-bash">php artisan config:publish --all</code></pre>
          </li>
          <li><strong>Спрощений файл маршрутів:</strong> API та WebSockets маршрути тепер не створюються за замовчуванням. Для їх додавання використовуються нові лаконічні команди:
            <pre><code class="language-bash">php artisan install:api
php artisan install:broadcasting</code></pre>
          </li>
        </ul>

        <h2>2. Нова точка входу у файл <code>bootstrap/app.php</code></h2>
        <p>Всі налаштування поведінки додатку, посередників (middleware) та винятків (exceptions) тепер сконцентровані в одному файлі <code>bootstrap/app.php</code>. Це значно спрощує глобальну конфігурацію:</p>
        <pre><code class="language-php">&lt;?php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;

return Application::configure(basePath: dirname(__DIR__))
    -&gt;withRouting(
        web: __DIR__.'/../routes/web.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    -&gt;withMiddleware(function (Middleware $middleware) {
        // Додавання глобальних посередників
        $middleware-&gt;web(append: [
            \App\Http\Middleware\LocalizationMiddleware::class,
        ]);
    })
    -&gt;withExceptions(function (Exceptions $exceptions) {
        // Кастомний рендеринг винятків
    })-&gt;create();</code></pre>

        <h2>3. SQLite за замовчуванням</h2>
        <p>Для нових додатків Laravel 11 тепер використовує SQLite як базу даних за замовчуванням. Це дозволяє розробникам розпочати роботу над проектом миттєво після запуску <code>laravel new</code>, без необхідності встановлювати локальні сервери MySQL чи PostgreSQL або налаштовувати Docker-контейнери на початкових етапах. База даних створюється автоматично у вигляді звичайного файлу всередині проекту.</p>

        <h2>4. Новий інструмент Laravel Reverb</h2>
        <p>Однією з найцікавіших новинок стала інтеграція <strong>Laravel Reverb</strong> — першокласного, неймовірно швидкого WebSocket сервера, розробленого спеціально для додатків Laravel. Він повністю написаний на PHP і сумісний з протоколом Pusher. Reverb дозволяє легко масштабувати real-time функціонал вашого додатку без сторонніх платних сервісів.</p>

        <h2>Висновок</h2>
        <p>Laravel 11 робить крок назустріч максимальній лаконічності коду та простоті масштабування. Нова структура може здатися незвичною на перший погляд, але вона значно прискорює створення та підтримку проектів. Оновлення до Laravel 11 — це чудовий спосіб підвищити продуктивність ваших розробників та додатку загалом.</p>
